## Why

原生 Claude Code 是 Anthropic 提供的命令行（CLI）工具，能力强大但交互形态是终端文本流，对非终端重度用户不友好：会话历史散落在终端回滚缓冲区、切换模型要记参数、多个任务并行时无法直观地在多个会话间来回切换。我们需要一个类 ChatGPT 的桌面客户端，把 CLI 的能力用图形界面接管，降低使用门槛，同时不魔改 CLI 本体，便于跟随官方版本升级。

## What Changes

- 新增一个桌面 GUI 应用，通过子进程调用本地已安装的 `claude` CLI，实现图形化对话收发。
- 新增图形化聊天界面：输入框发送消息，流式渲染 Claude Code 的回复（含 Markdown / 代码块），展示工具调用等中间过程。
- 新增模型切换能力：界面上可选择模型（如 Opus / Sonnet / Haiku 档位），选择结果作为 CLI 调用参数生效，并随会话持久化。
- 新增多会话管理：左侧会话列表可查看历史会话、新建会话、切换会话、重命名与删除；会话数据本地持久化，重启后可恢复。
- 支持本地运行与打包分发（可产出桌面安装包）。
- 全程维护两份中文说明文档：设计说明（架构 / 选型 / 文件结构 / 主动放弃项）与 AI 使用说明（用到的模型 / Agent / Skill / 组件 / 工具及问题与修正记录）。

本变更为纯新增，不修改任何既有能力，无 BREAKING 变更。

## Capabilities

### New Capabilities

- `gui-chat`: 图形界面内与 Claude Code 的对话交互——消息发送、流式回复渲染、中间过程（工具调用/思考）展示、错误与中断处理。
- `model-switching`: 在界面中选择并切换调用 Claude Code 时使用的模型，切换即时生效且随会话保存。
- `session-management`: 多会话的创建、列表展示、切换、重命名、删除与本地持久化，重启后可恢复历史会话及其上下文。

## Impact

- 新增代码：一个独立的桌面应用工程（GUI 层、CLI 子进程通信层、本地会话持久化层）。
- 外部依赖：本地需已安装并可用的 `claude` CLI，以及有效的 Anthropic 认证（沿用 CLI 自身的登录/密钥机制，本应用不额外管理密钥）。
- 运行时依赖：桌面应用运行时框架与前端 UI 依赖（具体选型见 design.md）。
- 平台范围：承诺并验收 Windows / macOS / Linux 三端，三项能力（聊天 / 模型切换 / 多会话）在各端均需通过验收。验收方式为三端各自手动跑通规格 scenario，安装包由 electron-builder 本地分别产出三端产物（CI 三端矩阵为后续可选项，非本版门槛）。三端因子进程调用 `claude` CLI 而各有平台差异（可执行形态、PATH、中断信号等），需在适配层分别处理，详见 design.md。
- 数据：在用户本地目录写入会话数据（会话元信息、消息记录、每会话所选模型），不上传第三方。
- 文档：新增 `docs/` 下的设计说明与 AI 使用说明；必要约定沉淀进项目 `CLAUDE.md` 或 skill。
