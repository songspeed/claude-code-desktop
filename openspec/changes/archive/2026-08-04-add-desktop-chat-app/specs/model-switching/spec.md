## Purpose

允许用户在桌面界面中选择并切换调用 Claude Code 时使用的模型档位，切换即时对后续消息生效，且所选模型随会话持久化保存。

## ADDED Requirements

### Requirement: 模型选择入口

系统 SHALL 在界面提供模型选择控件，展示可用的模型档位（如 Opus / Sonnet / Haiku 等），并高亮当前会话正在使用的模型。

#### Scenario: 展示可选模型

- **WHEN** 用户打开模型选择控件
- **THEN** 系统列出可用模型档位，并以选中态标示当前会话所使用的模型

### Requirement: 切换模型即时生效

用户选择新的模型后，系统 SHALL 将其作为后续 `claude` CLI 调用的模型参数，使切换在下一条消息发送时即时生效。

#### Scenario: 切换后新消息使用新模型

- **WHEN** 用户在模型选择控件中选择一个不同于当前的模型，随后发送一条新消息
- **THEN** 系统以新选择的模型参数调用 CLI 处理该消息

#### Scenario: 不影响已生成的历史消息

- **WHEN** 用户切换模型
- **THEN** 系统不修改或重新生成会话中已存在的历史消息，仅影响之后发送的消息

### Requirement: 模型选择随会话持久化

系统 SHALL 将每个会话当前所选模型随会话数据持久化保存，重新打开该会话时恢复其上次所选模型。

#### Scenario: 重启后恢复会话模型

- **WHEN** 用户为某会话选定模型后关闭并重新启动应用，再打开该会话
- **THEN** 系统恢复该会话上次保存的模型选择，并在模型选择控件中以选中态展示

#### Scenario: 新建会话使用默认模型

- **WHEN** 用户新建一个会话
- **THEN** 系统为该会话设置一个默认模型，用户可随时切换
