## Why

当前桌面客户端已具备聊天、会话和模型切换能力，但仍沿用早期深色聊天界面：信息层级松散、空会话没有有效起点、输入区缺少工作上下文。需要以跟随系统的浅色优先桌面工作台为默认体验，并提供稳定的手动主题切换，令界面更适合长时间的开发任务。

## What Changes

- 将应用默认视觉重构为浅色、克制的桌面工作台；深色主题作为完整的等价模式，而不是浅色样式的局部反色。
- 新增可持久化的外观偏好，支持浅色、深色与跟随系统；首次运行默认跟随系统。
- 重构侧栏为稳定的产品导航和会话区，在底部提供外观设置入口；保留既有会话创建、切换、重命名和删除行为。
- 为空会话新增居中欢迎区和面向 Claude Code 本地开发工作流的任务建议卡片，帮助用户探索项目、规划改动、修复问题或审查工作区；选择建议后将内容带入输入框供用户编辑或发送。
- 将聊天工作区调整为受限阅读列，并重构为上下文状态条与贴底独立输入框；输入框提供紧凑、明确的编辑与提交层级，模型和权限状态保持可见但不抢占输入空间。
- 统一色彩、边框、间距和组件状态所使用的语义化设计令牌，使消息、工具调用、错误、确认框和 Markdown 代码块在三种外观偏好下均可读且一致。

## Capabilities

### New Capabilities
- `workspace-appearance`: 管理应用的浅色、深色与跟随系统外观偏好，并在重启后恢复。
- `desktop-workspace`: 提供稳定的侧栏、空会话起始体验和面向开发任务的聊天工作区布局。

### Modified Capabilities
- 无。

## Impact

- 影响渲染层布局和样式：`src/App.css`、`src/App.tsx`、会话侧栏、聊天视图、输入框、消息和权限相关组件。
- 新增仅本地使用的外观偏好存储与 IPC 接口，沿用 Electron 用户数据目录，不涉及 CLI 调用、会话上下文或网络请求。
- Markdown 代码高亮样式需要随有效主题切换；实现时可引入图标库以替换文字和 emoji 操作符。
- 不改变现有会话数据格式、模型选择语义、CLI 权限模式或流式事件顺序。
