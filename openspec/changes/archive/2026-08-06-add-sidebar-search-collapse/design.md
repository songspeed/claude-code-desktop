## Context

当前客户端的会话侧栏始终展开，且仅支持滚动浏览。参考客户端提供了全局会话搜索弹窗与可收起侧栏。详见 `proposal.md`。

## Goals / Non-Goals

**Goals:**

- 为当前已加载的会话提供低成本、键盘可用的快速筛选。
- 让用户在任何主区域内容下收起或恢复侧栏。
- 保持现有会话选择、设置导航和项目关联行为不变。

**Non-Goals:**

- 不搜索或索引消息正文、工具调用内容或磁盘上的未加载会话数据。
- 不持久化侧栏展开状态，也不更改会话数据模型。
- 不新增全局命令面板或远程搜索接口。

## Decisions

### 搜索只基于内存会话元数据

搜索面板从 Zustand 中已有的会话列表派生结果，对标题和关联项目的末级目录名进行规范化匹配。空查询展示已有会话，匹配结果可由键盘索引选择。

这符合当前客户端的数据访问边界，并立即响应输入。相比搜索消息正文，不需要读取每个会话文件、建立索引或将内容暴露给新 IPC。

### 收起状态由应用壳层管理

应用壳层持有临时的 `sidebarCollapsed` 状态，并将收起请求传递给会话侧栏。侧栏以宽度过渡隐藏；主区域中的展开图标是唯一恢复入口。

使用局部 UI 状态避免修改持久化和会话存储。替代方案是把状态写入用户偏好，但用户尚未要求跨重启记忆，且会增加设置迁移范围。

### 搜索交互放在独立的模态面板

搜索面板位于应用内容之上，自动聚焦输入框，支持 Escape、上下箭头和回车。选择结果后调用已有会话切换动作并回到对话视图。

这延续参考客户端的高效入口，同时不会压缩会话列表或改变侧栏正常浏览布局。

## Risks / Trade-offs

- [会话标题重复] → 结果同时显示项目名和更新时间，仍按会话 ID 选择。
- [收起后用户不易发现恢复入口] → 主区域固定显示带明确无障碍名称与提示的展开图标。
- [系统快捷键与文本输入冲突] → 只响应带 Command 或 Ctrl 修饰键的 K，搜索面板内部保留标准输入快捷键。

## Migration Plan

1. 新增本地搜索面板和纯筛选逻辑测试。
2. 为侧栏品牌区接入搜索、收起按钮，并在应用壳层加入展开控制。
3. 验证搜索选择不会改变现有会话持久化，验证收放不影响当前视图。
4. 回滚时移除 UI 控件即可，会话数据和 IPC 无需迁移。
