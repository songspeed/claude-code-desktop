## Purpose

保证 Claude 回复中的富文本语法与路径引用被完整、正确地呈现，使输出可读且可操作。

## ADDED Requirements

### Requirement: 按 GitHub 风格渲染扩展语法

系统 SHALL 将正文 markdown 中的扩展语法按 GitHub Flavored Markdown 渲染：表格显示为带表头、有边框的表格；`- [ ]`/`- [x]` 任务列表显示为带复选框的列表；删除线、脚注等扩展语法正常渲染。

#### Scenario: 渲染表格
- **WHEN** 正文包含管道分隔的表格（表头行 + 分隔行 + 数据行）
- **THEN** 系统渲染为结构化表格，表头加粗、列与数据一一对应

#### Scenario: 渲染任务列表
- **WHEN** 正文包含 `- [ ]` 与 `- [x]` 前缀的列表项
- **THEN** 系统将每一项渲染为带复选框的列表项，已完成项保留勾选标记

#### Scenario: 渲染删除线与其他扩展
- **WHEN** 正文包含 `~~文本~~` 等 GFM 扩展语法
- **THEN** 系统按 GFM 语义渲染，不显示原始标记符号

### Requirement: 文件路径引用可点击打开

系统 SHALL 将正文中的 `路径:行号` 引用（如 `src/main.ts:12`）识别为可点击链接；点击后打开对应文件。相对路径 SHALL 基于当前会话工作区根目录解析；无法可靠解析（无工作区、路径越界、文件不存在）的引用 SHALL 保持不可点击。

#### Scenario: 点击工作区内的引用
- **WHEN** 正文包含 `src/main.ts:12` 且当前会话已关联包含 `src/main.ts` 的目录
- **THEN** 系统将该片段渲染为可点击链接，点击后系统打开该文件并定位到第 12 行

#### Scenario: 无工作区时保持不可点击
- **WHEN** 会话未关联项目目录，正文包含 `src/main.ts:12`
- **THEN** 该片段不渲染为可点击链接，且不触发任何错误提示

#### Scenario: 抑制误匹配
- **WHEN** 正文中的 `数字:数字` 片段不构成路径（如时间 `12:30`）
- **THEN** 系统不将其识别为路径引用
