## Purpose

让用户能在发送任务前明确查看并选择当前会话可实际执行的 Claude Code 授权模式，避免界面选项与无头 CLI 的权限行为不一致。

## ADDED Requirements

### Requirement: 展示可执行的会话授权模式

系统 SHALL 在组合器中展示当前会话的授权模式，并允许用户在未生成回复时选择自动接受编辑、仅规划、拒绝未授权工具或全部放行四种模式。系统 SHALL 使用与 Claude Code CLI 一致的模式标识启动后续消息，且 SHALL NOT 展示当前传输层无法可靠完成的逐工具确认模式。

#### Scenario: 选择受支持的授权模式

- **WHEN** 用户在未生成回复时从授权模式控件选择一种模式
- **THEN** 控件立即显示该模式的可读名称，且下一条消息使用该模式调用 Claude Code CLI

#### Scenario: 生成期间锁定授权模式

- **WHEN** Claude Code 正在生成当前会话的回复
- **THEN** 授权模式控件不可修改，直到该次生成完成或被停止

### Requirement: 全部放行需要风险确认

系统 SHALL 在用户从其他授权模式切换到全部放行前显示风险确认，说明该模式会跳过权限检查并可能直接执行命令或修改文件。用户取消确认时，系统 SHALL 保持此前的授权模式。

#### Scenario: 确认后启用全部放行

- **WHEN** 用户选择全部放行并在风险确认中确认
- **THEN** 当前会话的授权模式切换为全部放行，组合器显示该模式

#### Scenario: 取消全部放行

- **WHEN** 用户选择全部放行但取消风险确认
- **THEN** 当前会话的授权模式保持不变，后续消息不使用全部放行
