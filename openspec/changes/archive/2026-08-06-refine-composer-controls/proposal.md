## Why

当前输入区只显示简略模型名称和一个“危险放行”开关，用户无法在提交前清楚判断模型 CLI 别名、授权行为或输入可用性。参考客户端已将这些上下文收敛为组合器的稳定控制区，适合作为当前桌面客户端的改进方向。

## What Changes

- 在模型选择中显示产品名称与对应的稳定 Claude CLI 别名，并在生成期间锁定模型变更。
- 将单一危险开关替换为会话级授权模式选择，提供自动接受编辑、仅规划、拒绝未授权工具和全部放行；全部放行仍需显式二次确认。
- 将所选授权模式随会话持久化，并仅从主进程保存的会话状态启动 Claude CLI。
- 更新输入框文案，使项目目录未关联、CLI 不可用、生成中和可输入状态均有准确提示。
- 优化组合器控制布局，使项目、授权、模型和发送操作在窄窗口中保持稳定、不遮挡。

## Capabilities

### New Capabilities
- `composer-permission-controls`: 在组合器中管理可执行的会话授权模式，并对全部放行提供风险确认。

### Modified Capabilities
- `model-switching`: 模型控件显示稳定 CLI 别名，并在生成期间保持不可变。
- `gui-chat`: 输入框根据项目关联、CLI 状态和生成状态显示可执行的提示与可用性。
- `session-management`: 会话记录并恢复所选授权模式。

## Impact

- 影响会话类型与 JSON 迁移、主进程发送参数、preload/IPC、Zustand 状态和组合器相关组件。
- 移除全局临时的危险放行开关，改为每个会话持久化的授权模式。
- 不新增依赖，不启用当前 CLI 传输层无法可靠回传的逐工具确认模式。
