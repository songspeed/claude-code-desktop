## ADDED Requirements

### Requirement: 失败或中断的回合可重试

系统 SHALL 在失败或中断的回合上提供「重试」操作：重发该回合的最后一条用户消息，产生新的回合。正常完成的回合 SHALL 不提供重试操作。

#### Scenario: 中断回合重试
- **WHEN** 回合被用户中断，界面上存在该回合的用户消息与部分正文
- **THEN** 该回合显示「重试」按钮，点击后系统以同一用户消息发起新回合，新回合独立记录

#### Scenario: 失败回合重试
- **WHEN** 回合因 CLI 错误失败
- **THEN** 该回合显示「重试」按钮，点击后重新发送该回合的用户消息

#### Scenario: 完成回合无重试
- **WHEN** 回合正常完成
- **THEN** 该回合不显示「重试」按钮

### Requirement: 复制整回合正文

系统 SHALL 为包含正文的回合提供「复制整回合」操作，将本回合全部 markdown 正文（含追加内容）一次性复制到剪贴板。回合无正文时 SHALL 禁用该操作。

#### Scenario: 复制完整内容
- **WHEN** 回合包含多条正文（含后续追加）且用户点击「复制整回合」
- **THEN** 剪贴板包含按时间顺序拼接的全部 markdown 文本

#### Scenario: 无正文时禁用
- **WHEN** 回合没有任何正文（仅工具活动或仅系统通知）
- **THEN** 「复制整回合」不可用且点击不产生任何效果
