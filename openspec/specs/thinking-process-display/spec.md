# thinking-process-display Specification

## Purpose
在 Claude 生成回复期间以不打断正文阅读的折叠形式实时展示思考过程，并在思考过程中提供估算 token 数的可见反馈；思考过程仅实时可见，不写入会话记录。
## Requirements
### Requirement: 流式显示思考过程

系统 SHALL 在回合生成期间将传输提供的思考增量以独立于助手正文的折叠块实时展示；用户展开后 SHALL 看到截至当前的累计思考全文。思考内容 SHALL NOT 混入助手 Markdown 正文的渲染。

#### Scenario: 思考块随增量更新

- **WHEN** 传输持续提供思考增量
- **THEN** 系统在独立折叠块中累计思考内容，展开后可见当前全部思考全文

#### Scenario: 思考与正文相互独立

- **WHEN** 同一回合同时存在思考增量与正文增量
- **THEN** 思考显示在独立折叠块中，正文按 Markdown 渲染，二者互不插入

### Requirement: 思考块显示实时估算 token 数

系统 SHALL 在思考块中显示传输提供的实时估算思考 token 数，并在思考流式期间持续更新；传输未提供估算值时，系统 SHALL 仅显示状态文案，不显示数字。

#### Scenario: 估算 token 实时更新

- **WHEN** 传输在思考流式期间持续提供估算 token 数
- **THEN** 思考块中的估算数值随事件到达持续更新

#### Scenario: 无估算数据

- **WHEN** 传输未提供估算 token 数
- **THEN** 思考块仅显示状态文案，不显示数字或占位值

### Requirement: 思考过程不持久化

系统 SHALL NOT 将实时思考过程写入会话记录；回合结束后思考块从界面移除，重新打开会话后思考内容不可见。

#### Scenario: 回合结束后思考块消失

- **WHEN** 回合结束且思考块正在展示
- **THEN** 系统移除实时思考块，不在消息流中保留任何思考内容

#### Scenario: 重新打开会话无思考内容

- **WHEN** 用户重新打开包含已生成回合的会话
- **THEN** 会话记录与界面中均不出现任何思考过程内容
