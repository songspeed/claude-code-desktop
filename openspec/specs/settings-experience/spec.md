# settings-experience Specification

## Purpose

为桌面客户端提供独立、可检索并能安全编辑的设置工作区，使用户能在不干扰当前开发会话的前提下快速查找、调整和确认本地偏好。

## Requirements

### Requirement: 独立的设置工作区

系统 SHALL 在用户进入设置时显示设置专用导航与内容区，而非与会话列表同时构成两级侧栏。设置工作区 SHALL 提供明确的返回应用操作，返回后保留此前激活的会话和聊天上下文。

#### Scenario: 从会话工作区进入设置

- **WHEN** 用户点击设置入口或触发设置快捷键
- **THEN** 系统显示设置专用导航、搜索入口和当前设置内容，并不显示会话列表作为设置导航的一部分

#### Scenario: 返回正在进行的工作

- **WHEN** 用户在设置工作区执行返回应用操作
- **THEN** 系统返回此前的聊天工作区，并保留原先激活的会话、消息和生成状态

#### Scenario: 在窄窗口中浏览设置

- **WHEN** 设置工作区处于现有支持的窄宽度
- **THEN** 设置导航和内容区在各自容器内保持可访问，分组、搜索和返回操作不与文本或控件重叠

### Requirement: 可检索且可通过键盘进入的设置

系统 SHALL 提供 `CmdOrCtrl+,` 作为打开设置的快捷键，并在设置工作区提供搜索设置入口。搜索 SHALL 匹配设置页面、可见字段和可执行操作的名称及说明，且 SHALL NOT 搜索用户配置值、会话内容或本地文件路径。

#### Scenario: 使用设置快捷键

- **WHEN** 用户按下 `CmdOrCtrl+,`
- **THEN** 系统打开设置工作区并将键盘焦点置于设置搜索入口

#### Scenario: 搜索并定位设置

- **WHEN** 用户输入与设置页面、字段或操作匹配的搜索词并选择结果
- **THEN** 系统打开对应设置页，将键盘焦点移至匹配控件或其可访问标题，并清晰标示当前页

#### Scenario: 保持会话搜索可用

- **WHEN** 用户在聊天工作区按下现有的 `CmdOrCtrl+K`
- **THEN** 系统继续打开会话搜索，而不是替换为设置搜索

### Requirement: 按职责组织设置导航

系统 SHALL 按应用、Agent 与模型、工具与集成等实际拥有内容的职责对设置入口分组。入口名称 SHALL 与对应页面提供的控制相符，且系统 SHALL NOT 为尚未支持的设置显示空分组或占位页面。

#### Scenario: 查看 Agent 配置入口

- **WHEN** 用户浏览设置导航
- **THEN** Claude 用户模型和本地 CLI 状态位于名称准确的 Agent 与模型入口，而非语义宽泛的通用配置入口

#### Scenario: 浏览现有设置页

- **WHEN** 用户打开外观、语言、Skills 或关于页面
- **THEN** 系统保留现有页面的功能，并在其所属的有内容分组下展示该入口

### Requirement: 安全完成 Claude 配置编辑

系统 SHALL 在 Claude 模型配置存在未保存变更时，阻止用户在未作选择的情况下切换设置页或返回应用，并提供保存、放弃和继续编辑操作。系统 SHALL 在写入成功前不显示已保存状态，并为不符合本地字段约束或写入失败的值提供可理解的错误反馈。

#### Scenario: 带未保存配置尝试离开

- **WHEN** 用户修改 Claude 模型配置后尝试切换设置页或返回应用
- **THEN** 系统提示用户保存、放弃或继续编辑，且在用户作出选择前保持当前配置草稿

#### Scenario: 保存有效配置

- **WHEN** 用户提交符合字段约束的模型配置且本地写入成功
- **THEN** 系统持久化该配置并显示稳定的已保存反馈

#### Scenario: 配置保存失败

- **WHEN** 模型配置不符合字段约束或本地写入失败
- **THEN** 系统保留用户输入、标示相关错误，并不将配置标记为已保存

### Requirement: 可处理的本地 CLI 健康状态

系统 SHALL 在 Agent 与模型设置中展示当前本地 Claude CLI 的可用性和已知版本，并提供刷新该状态的操作。CLI 不可用时，系统 SHALL 显示可理解的修复方向，而不是仅显示技术错误。

#### Scenario: CLI 可用

- **WHEN** 本地 Claude CLI 已被检测到
- **THEN** 系统显示可用状态及已知版本，并允许用户手动刷新状态

#### Scenario: CLI 不可用

- **WHEN** 本地 Claude CLI 未安装、不可执行或无法检测
- **THEN** 系统在 Agent 与模型设置中显示不可用状态和下一步修复说明，且其他设置页面保持可用
