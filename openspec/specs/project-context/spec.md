# project-context Specification

## Purpose

让每个图形界面会话明确关联一个本地项目目录，并确保 Claude Code 只在用户选定且仍可访问的目录中运行。

## Requirements

### Requirement: 会话关联本地项目目录
系统 SHALL 允许用户为每个会话通过系统目录选择器关联或更改本地项目目录。该目录关联 SHALL 随会话持久化，并在重启后恢复。

#### Scenario: 为会话选择项目目录
- **WHEN** 用户在未关联目录的会话中选择一个本地目录
- **THEN** 系统将该目录关联到当前会话，并在工作区中显示其名称和完整路径

#### Scenario: 更改已有会话的项目目录
- **WHEN** 用户为已有目录关联的会话选择另一个本地目录
- **THEN** 系统使用新目录更新该会话的项目上下文，并在重启后保留新关联

### Requirement: 在关联目录中执行 Claude
系统 SHALL 将当前会话关联的本地项目目录作为 Claude CLI 的工作目录。系统 MUST 在启动 CLI 前确认目录可访问。

#### Scenario: 在项目目录中发送任务
- **WHEN** 用户在已关联且可访问的项目目录的会话中发送消息
- **THEN** Claude CLI 在该项目目录中启动并处理该消息

#### Scenario: 缺少或失效目录时阻止发送
- **WHEN** 当前会话未关联目录，或关联目录已不存在且用户尝试发送消息
- **THEN** 系统不启动 Claude CLI，并向用户展示需要选择可访问项目目录的明确提示

### Requirement: 目录操作保持安全边界
系统 SHALL 仅通过主进程提供目录选择和在系统文件管理器中显示目录的能力。渲染层 MUST NOT 获得通用文件系统或命令执行访问能力。

#### Scenario: 从工作区显示项目目录
- **WHEN** 用户选择在系统文件管理器中显示当前项目目录
- **THEN** 系统请求主进程显示该已关联目录，且不向渲染层公开额外文件系统权限
